The 5Vs of Big Data in CrowdCare

Crowd monitoring systems generate massive amounts of data. This project demonstrates the 5Vs of Big Data.

1. Volume

Through the Big Data Gen page, we can generate up to 100,000 records across 40 simulated zones to demonstrate how the system handles large-scale data storage and querying.

2. Velocity

The Live AI Camera module pushes new data frames to the server every 5 seconds, illustrating the rapid speed at which real-time streaming data must be ingested and processed.

3. Variety

The system handles multiple data types: structured relational data (SQLite), unstructured binary data (Camera Images), and geographical data (Lat/Lon coordinates).

4. Veracity

AI models inherently contain noise. We clean and filter the data (e.g., using confidence thresholds > 0.4 in the MobileNet-SSD) to ensure the data is accurate before triggering alerts.

5. Value

Raw numbers are useless without context. Our Analytics Dashboard extracts value from the data by predicting peak hours, identifying dangerous zones, and automatically assigning responders to save lives.
