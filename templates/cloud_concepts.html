Cloud Computing Concepts in CrowdCare

This prototype demonstrates core cloud computing principles using a localized Client-Server model.

1. Client-Server Architecture

The Android phones act as Mobile Edge Clients. They capture raw images and stream them over the network to a central processing unit. The Laptop running the Flask API acts as the Cloud Server, handling requests, running heavy AI logic, and serving responses.

2. Cloud Object Storage Simulation

In a real production environment, images and incident logs are stored in scalable services like AWS S3 or Google Cloud Storage. In this project, the cloud_storage/ directory simulates this by isolating raw data storage from the relational database.

3. Resource Pooling & Scalability

The server can theoretically process images from dozens of cameras (Camera 1, 2, 3...) simultaneously, showcasing how cloud resources are pooled to serve multiple clients on demand.

4. Network Data Accessibility

All data is centralized in the cloud database (SQLite) and made accessible universally through this web dashboard, ensuring that officers and marshals have real-time synchronization regardless of their physical location.
